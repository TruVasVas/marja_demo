# marja_demo
ДШ по маржинальности демо 

## Демонстрационный дашборд

Откройте `index.html` в браузере. Установка зависимостей не нужна, приложение работает без внешних запросов и без доступа к кабинету продавца.

Для локальной разработки:

```sh
cd /workspace/marja_demo
python3 -m http.server 8080 --bind 0.0.0.0
```

Вымышленные данные: 10 SKU, 2 убыточных, 3 с маржой около 5%, 5 с маржой выше 10%. Два режима расчёта, поиск, фильтр, сортировка и выгрузка CSV. Дата меняет подпись отчёта; демонстрационные суммы от даты не зависят. Статусы являются примерами, подключения к API нет.

Прибыль рассчитана после семи категорий расходов. Комиссия подобрана для заданной демонстрационной маржи и не является реальным тарифом маркетплейса. Итоги верхней сводки относятся ко всем SKU, итоги таблицы — к отфильтрованным.

## Публичная ссылка

Для публикации на GitHub Pages загрузите файлы в репозиторий, затем в Settings → Pages выберите Deploy from a branch, ветку с файлами и каталог `/ (root)`. Дождитесь успешной публикации; точный URL покажет GitHub. Альтернативно загрузите `index.html` на свой статический хостинг. Сам запуск локального сервера публичную ссылку не создаёт.

Обложки товаров находятся в `assets/products.png`: десять сгенерированных реалистичных изображений для вымышленных товаров, без сторонних брендов. При публикации необходимо загрузить каталог `assets` вместе с `index.html`.

### Режим «По цене дня»

Отдельный плотный отчёт по образцу исходного дашборда: девять счётчиков, дата расчёта и таблица из 17 столбцов с изображениями, источниками, обычной и управленческой прибылью/маржой. Обе прибыли рассчитаны для одной продажи. Обычная прибыль учитывает рекламу SKU (демо: 6,50% цены); управленческая заменяет её распределённой рекламой кабинета (4,59% цены). Дополнительные расходы составляют 1,40% цены. Комиссия подобрана под демонстрационную управленческую маржу. Источники и статусы вымышлены; точных цен — 9, восстановленных — 1, FACT — 4, MIXED — 3, FORECAST — 3. Экспорт цены дня содержит все поля расчёта. Поиск, фильтр и сортировка доступны в режиме «По заказам».
